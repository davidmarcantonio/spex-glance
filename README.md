# Spex Glance has moved

Spex Glance now lives at **[spexbet/spex-glance](https://github.com/spexbet/spex-glance)**.
Download it from **[spex.bet/glance](https://spex.bet/glance/)** or with Homebrew:

```sh
brew install --cask spexbet/tap/spex-glance
```

This repository only keeps `appcast.xml`, so copies of Spex Glance 0.3.1 and earlier can update. The update
moves them to the new feed on spex.bet. Please open issues on the new repository.
